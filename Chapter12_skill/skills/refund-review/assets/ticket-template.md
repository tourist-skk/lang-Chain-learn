# 退款工单模板

调用 `service_create_mock_ticket` 时，按下表填写参数：

| 参数 | 填写要求 | 示例 |
|---|---|---|
| `order_id` | 订单号 | A1001 |
| `decision` | “全额退款”或“退还 50%” | 全额退款 |
| `refund_amount` | 退款金额，单位元 | 2388 |
| `reason` | 一句话说明满足了哪些条件 | 付款 4 天，AI 问答使用 7%，未开票，未升级 |
| `evidence` | 依据的规则片段编号，用逗号分隔 | 片段14,片段15 |

工单创建后状态为“待处理”，由人工完成后续退款操作。
